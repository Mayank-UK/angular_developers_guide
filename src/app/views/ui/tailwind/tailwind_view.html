Tailwind is loaded for this screen only: the Play CDN <script> is attached in ngOnInit and removed — along with every <style> it generates — in onDestroy via DestroyRef. The rest of the app keeps using its own var(--…) token design system. Trade-off: while this screen is mounted the Play CDN is a runtime compiler that is technically document-wide (Preflight, the base reset, is disabled on load to spare the app's chrome). The moment you navigate away, the script and its generated styles are gone.
